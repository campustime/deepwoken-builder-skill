# Deepwoken Builder

## Overview
Deepwoken Builder is a web‑based tool for planning and analyzing character builds in the Roblox game **Deepwoken**. It helps players explore stats, talents, mantras, weapons, and equipment to understand how different choices affect a build.

**Website:** https://deepwokenbuilder.org

## How to Use
1. Provide Claude with a build link from DeepwokenBuilder.org  
2. Or describe the type of build you want (e.g., “flamecharm bruiser” or “heavy weapon posture build”)  
3. Claude will analyze the build, explain stats and talents, and suggest optimizations  
4. You can ask follow‑up questions such as comparisons, alternatives, or explanations of specific mechanics  
5. Adjust your build on the website and repeat as needed

## What This Skill Does
This skill enables Claude to:

- Interpret and explain builds created on DeepwokenBuilder.org  
- Break down stats, talents, mantras, and equipment  
- Suggest build ideas based on user goals or playstyle  
- Compare different stat spreads or build paths  
- Help users understand game mechanics using publicly available data  

Claude does **not** automate gameplay or interact with Roblox.  
It only provides information and planning assistance.

## Use Cases
- “Help me create a heavy weapon build with high posture damage.”  
- “Explain the difference between these two mantras.”  
- “Compare these two stat spreads for PvE.”  
- “Suggest equipment for a flamecharm bruiser build.”  
- “Summarize the strengths and weaknesses of this build link.”  

## Features
- Build parsing and explanation  
- Talent and mantra breakdowns  
- Equipment and weapon stat interpretation  
- Build optimization suggestions  
- Beginner‑friendly explanations of complex mechanics  

## Limitations
- Does not interact with Roblox or modify gameplay  
- Uses only publicly available data from DeepwokenBuilder.org  
- Game mechanics may change with updates  
- Build viability cannot be guaranteed  

## Privacy
This skill does not collect personal data.  
Build links provided by users are processed only to generate explanations or suggestions.
