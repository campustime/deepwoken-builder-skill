# deepwoken-builder-skill

This repository contains the official Claude Skill definition for **Deepwoken Builder**, a web‑based tool for planning and analyzing character builds in the Roblox game *Deepwoken*.

The skill enables Claude to interpret build links, explain stats and talents, compare build paths, and help users understand game mechanics using publicly available data from DeepwokenBuilder.org.
